⚙️ WebPilot AI 设置

接入任意 OpenAI 兼容 API，驱动你的浏览器智能体
💡 推荐使用 Rqu AI（本插件默认网关）： 一个 Key 即可调用 GPT / Claude / Gemini / DeepSeek / 通义千问等全部主流模型。 前往注册获取 API Key →
任何 OpenAI 兼容端点均可。官方 API 填 https://api.openai.com/v1
依赖模型调用工具（function calling），推荐 GPT-4o-mini / DeepSeek 等支持工具调用的模型
单次任务最多进行的"模型决策-工具执行"循环次数
定时把任务交给智能体执行（无人值守）。发布/评论类操作默认会被安全机制拒绝——建议任务里写明"生成草稿"， 人在面板确认后再发。凭据登录请先在「网站凭据」中保存账号。
供智能体自动登录你自己的账号使用。凭据仅存储在本机（chrome.storage.local），不会同步、不会上传。 请勿保存他人账号。支持平台验证码/2FA 时智能体会暂停并请求你介入。
技能 = 可安装的任务流程指令包。智能体完成任务后会自动把可复用流程沉淀为新技能（下方标记 🤖 的即自学产物）， 也可以从 URL 或粘贴 JSON 安装社区技能。
通过 Streamable HTTP 传输接入 MCP 服务器，其工具自动注入智能体（工具名前缀 mcp__服务器名__）。 本地 stdio 型 server 请先用 mcp-proxy 转成 HTTP（见项目 README）。
